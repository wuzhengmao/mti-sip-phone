# mti-sip-phone 用户使用手册

> 面向**最终用户**：安装、配置、日常打电话、视频通话，以及出问题时的排查办法。
> 开发集成（网页控制）请看 [sdk-guide.md](sdk-guide.md)。

## 1. 这是什么

一款常驻**系统托盘**的桌面软电话：

- 语音通话（PCMA / PCMU / Opus / G.722），视频通话（H.264 / VP8 / VP9 / H.263）
- 通话记录、通信录、DTMF 按键、通话保持
- 可选的信令加密（TLS）与媒体加密（SRTP）
- 可被网页控制（本地 WebSocket 接口 + JS SDK）
- 自动更新（有新版会提示，你确认后才下载安装）

下载页上有**两个版本**，功能完全一样，区别只在界面：

| 版本 | 界面 |
| --- | --- |
| **完整版**（`mti-sip-phone-*`） | 桌面窗口：主界面 + 通话面板 + 视频窗口，另有托盘；也带网页控制台 |
| **仅托盘无 UI 版**（`mti-sip-phone-no-ui-*`） | **只有托盘图标**，不弹任何窗口；点托盘图标用浏览器打开网页控制台来操作（适合"机器只当话机用、由浏览器统一操作"的场景） |

## 2. 安装与运行环境

| 系统 | 说明 |
| --- | --- |
| Windows | **要求 Windows 10 及以上**（不支持 Windows 7/8）。单文件、**免安装** |
| Linux | 需要带桌面的发行版（X11 或 Wayland）；glibc 版本不低于打包环境 |
| macOS | **要求 12 及以上**（Apple Silicon 与 Intel 都支持）。应用**未做 Apple 签名/公证**，首次打开请**右键 → 打开**（或终端执行 `xattr -cr <应用>.app`），之后正常双击即可。视频通话暂不支持（摄像头采集未实现） |

- 程序是**单个可执行文件**，下载后放到任意目录双击即可，**不需要安装、不写注册表**
  （Windows 版的"开机自启"会写当前用户注册表项，见下）。
- **首次运行会自动"安装"到固定位置**：程序把自己复制到固定数据目录（Windows
  `%APPDATA%\mti-sip-phone\`、Linux `~/.local/share/mti-sip-phone/`）、**在桌面生成
  「MTI 软电话」快捷方式**，并从那里继续运行——以后无论从下载目录、桌面还是别的什么地方启动都一样，下载的文件
  被清理工具删掉也不影响使用（自动更新、开机自启、sip:// 拉起都围绕固定位置）。
  **macOS** 稍有不同：程序图标和 sip:// 处理只能来自 `.app` 应用包，所以首次运行会在
  `~/Library/Application Support/mti-sip-phone/` 生成**应用包**（完整版 `MTI软电话.app` /
  无 UI 版 `MTI软电话-无UI版.app`）、在桌面放一个指向它的链接，再从包内重启；也可以直接使用
  分发页的 **DMG**——把应用拖进「应用程序」即可，不会再复制到别处。
- 启动后**常驻系统托盘**（Windows 在任务栏右下角；Linux 在托盘区），不占用任务栏。
  **关闭主窗口 = 隐藏到托盘**，程序继续运行（这是设计行为，不是退出）。
- **退出**请用托盘图标右键菜单里的「退出」。
- **开机自启**：默认开启（Windows 写当前用户注册表启动项；Linux 写 `~/.config/autostart`；
  macOS 写 `~/Library/LaunchAgents/cn.mti.sip-phone.plist`）。
  不需要时在配置页取消勾选。
- 数据目录（配置、通话记录、通信录、日志，以及自安装后的程序本体）：
  - Windows：`%APPDATA%\mti-sip-phone\`
  - Linux：`~/.config/mti-sip-phone/`（数据）、`~/.local/share/mti-sip-phone/`（程序本体）

## 3. 第一次使用：配置账号

主窗口右上角有三个图标按钮：**通话记录、通信录、配置**。点「配置」进入配置页
（**通话中不可进入**；左上角返回箭头回拨号页）。保存方式：**大部分选项改动即存**
（音频/视频设备、预处理开关、勾选项等），**SIP 账户要按「保存并注册」、日志要按
「保存日志配置」**。配置页从上到下：

### 常规

- **开机自动启动**：默认勾选（Windows 写注册表启动项；Linux 写 `~/.config/autostart`），改动即存。

### SIP 账户（必填）

先勾选「**启用账户**」，然后填写：

| 项 | 说明 |
| --- | --- |
| SIP 服务器 | 服务器地址，**端口可写在一起**：`10.168.4.40:15060`（省略端口则用默认 5060） |
| 账号 / 密码 | SIP 账号与密码；认证 ID 留空时同账号；显示名可选 |
| 传输 | `udp`（默认）/ `tcp` / `tls`。**tls = 信令加密**（SIPS），端口一般 5061 |
| 校验服务器证书 | 选 `tls` 后出现。**默认不校验**（方便内网自签证书）；公网或严格环境请勾选 |
| 域名（可选） | 只影响 SIP 地址里的"域"部分；留空 = 用服务器地址。多数情况不用填 |
| 声明 IP（可选） | 对外声明本机地址（NAT 环境用）。**留空 = 自动**；下拉里是本机网卡，也可手填 |
| 注册到期时间 | 默认 300 秒。网络不稳定可适当调大 |
| 启用 rport | 默认开启（NAT 穿透），一般不用动 |
| 代理服务器（可选） | 走代理时填 `主机:端口` |
| 启用 STUN | 公网地址探测。**内网/局域网建议关闭**（默认关闭）；开启后填 STUN 服务器（默认 `stun.l.google.com:19302`） |
| 媒体加密 | 通话内容加密（SRTP），四档：**关闭 / 支持（默认）/ 建议 / 必要**。「支持」= 本端不主动要求，对端要求就配合；「必要」= 对端不支持加密就拒绝通话。⚠️ **密钥随信令明文传递，只有配合 TLS 传输才有真正的保护** |

填完点「**保存并注册**」。填好后看主窗口顶栏的**状态圆点**：灰=未注册、黄=注册中、
**绿=已注册**、红=注册失败（旁边有文字与原因）。

**登录 / 退出账号**：「**启用账户**」这个勾选同时也是**是否注册的总开关**（默认勾选）——
取消勾选并保存 = 退出账号（立即注销、停止注册周期，下次启动也不注册）。平时更方便的
做法是用**托盘图标右键菜单**：在「显示主界面」下面——
- 已注册 / 注册中：显示「**退出账号**」；
- 未注册 / 注册失败：显示「**登录账号**」。
两种方式改的是同一个配置项。

> 用 `sip://` 链接拉起软电话时**总会登录并注册**（同时重新勾上「启用账户」）——
> 链接本身就是"要登录"的明确指令。

**服务端远程控制 / 注销通知**：服务器可通过 SIP `NOTIFY`（`Event: MSP_*`）远程控制
本机——远程拨号（`MSP_DIAL`）、远程接听（`MSP_ANSWER`）、远程挂断（`MSP_HANGUP`）、
改自动接听开关（`MSP_SET_AUTOANSWER`）、要求下线（`MSP_UNREGISTER`，如坐席被后台
踢下线）。收到下线通知后程序会**记日志、立即退出账号**（取消注册并禁用账户），之后需
点托盘「登录账号」或重新用 `sip://` 拉起才会再登录。远程拨号/接听里若请求视频，但
话机未开启视频或来电不含视频，会**自动降级为纯音频**。只接受来自注册服务器的通知，
其它来源一律忽略。

### 音频设备

- **麦克风 / 扬声器**：默认"系统默认设备"，可指定；**振铃扬声器**可单独指定（比如让来电铃声从外放响、通话走耳机）。
- **刷新设备**：插入新耳麦后点它重新枚举。
- **音频预处理**：
  - **回声消除**（默认开）：外放时对方听到自己回声就靠它，**建议保持开启**。
  - **降噪**（默认开）：过滤风扇/键盘等环境噪声。
  - **自动增益**（默认关）：自动调麦克风音量。**开着它会和你手动调的音量"打架"**，除非确实需要，否则保持关闭。
- 三项改完**从下一通电话生效**。

### 视频设备

- **启用视频通话**（总开关，默认开）：取消勾选后，视频呼叫、视频接听按钮全部隐藏。
- **摄像头**：下拉首项「系统默认」，末项「禁用（不发送本地视频）」；选禁用后：发视频呼叫
  不发送本地画面、来电也不显示「视频接听」按钮，**但仍能查看对方的视频**。
- **刷新设备**：插拔摄像头后点它重新枚举。

### 日志

- **记录日志到文件**（默认开）、**日志级别**（默认 info，排查时可调 debug）。
- **日志目录**：默认在数据目录下；「选择目录...」可更改、「打开日志目录」直达；
  改完点「保存日志配置」。
- **记录 SIP 信令**：排查通话问题时勾选（记录收发的 SIP 报文，**密码与密钥会自动打码**）。
  日常保持关闭，避免日志过大。

### 网页接入（WS 端口）

- **WS 端口**：本地网页控制服务端口，默认 8765（被占用自动 +1）；**修改后需重启**，
  程序会弹窗询问是否立即重启。

### 自动更新

- **更新站点**：留空 = 不检查更新（默认）；填站点地址后，程序按周期自动查询。
- **检查周期**：默认 5 分钟。
- **接受预览版**：默认关；勾选后可收到预发布版本。

## 4. 日常使用

### 拨号

- 主窗口顶栏从左到右：**注册状态圆点 + 文字**、**自动接听**开关、三个图标按钮
  （通话记录 / 通信录 / 配置）。
- 中间是号码输入框（占位提示「输入号码或 sip:xxx@主机」）与 3×4 拨号盘；
  **在窗口任意位置敲数字/星号/井号**也会输入（无需先点输入框），退格删除最后一位。
- **回车**（输入框里或窗口任意位置）= 拨打输入框里的号码。
- 输入框右侧的下拉是**最近呼出的号码**（最多 5 个），可快速重拨。
- 绿色「呼叫」按钮 = 语音呼叫；右侧摄像头图标 = **视频呼叫**（视频不可用时隐藏）。
- 呼出后按钮变红（= 挂断），等待对端接听；对端接听前挂断就是"取消呼叫"。

> 小技巧：在号码框里**直接输入名称**（汉字、全拼或拼音首字母，如 `zs`/`zhangsan`/`张三`）——
> 下面会列出通信录里匹配的人（带备注与 ★）以及最近呼叫过的相近号码，点一下就把号码填进输入框。

### 来电

- 来电会弹出**振铃窗口**（可置顶）：显示来电号码/名称（命中通信录时显示名称与备注）。
- **接听**（绿色话机图标）= 只接语音（不接受视频，即使对方是视频呼叫）；
  **视频接听**（绿色摄像头图标，仅对方带视频时出现）= 打开摄像头双向视频
  （没有摄像头或摄像头被禁用时自动变成"只看对方"）；
  **挂断**（红色图标）= 拒接（对方听到忙音）。**关闭振铃窗口也等于拒接**。
- **自动接听**（主窗口顶栏的开关）：开启后来电自动接通；视频来电等同「视频接听」。
- 错过来电：桌面通知 + 通话记录里的**未接**标记（红色）。

### 通话中

通话时显示**通话面板**：无边框、固定小尺寸、默认吸附屏幕右下角（多开会自动错开）；
**拖顶部的小横条**可移动，位置会被记住。三行分别显示：**对端号码/名称**、**状态字**
（呼叫中 / 来电 / 通话中）、**时长**，右侧是各图标按钮：

| 操作 | 说明 |
| --- | --- |
| **接听 / 挂断 / 视频接听** | 绿色话机 / 红色 / 绿色摄像头图标；振铃阶段点红色 = 取消呼叫或拒接 |
| **保持** | 黄色暂停图标 = 保持（走信令，对端会看到）；保持中变蓝色，再点恢复。与麦克风开关是两回事 |
| **麦克风 / 扬声器图标** | 纯本地开关（点一下开/关）；**在按钮上滚动滚轮可调音量（每格 5%）**：麦克风 0–200%（超过 100% 的部分在蓝色之上叠橙色），扬声器 0–100%；**调到 0% 就是关闭**。滚动时会弹出当前音量提示 |
| **视频开关** | 关闭本次通话的视频（不看对方、也不推本地画面）；**仅在本次通话协商到视频时出现** |
| **数字键** | 通话中在主窗口或通话面板敲数字 = 发送 DTMF（对方听到按键音）；通话中主窗口只放开数字键 |

- 通话音量、开关状态在**本次通话内**记忆（下一通恢复默认）。
- 通话时主窗口自动隐藏；通话结束自动恢复。

### 视频通话

- **视频呼叫**：拨号时点摄像头按钮；**视频接听**：来电窗口的对应按钮。
- 视频窗口显示对方画面；**右上角小窗是本地回显**（自拍预览，可单独开关——关闭只影响你自己
  的显示，不影响推送给对方、也不影响网页订阅）。振铃阶段对方画面还没来时，回显会铺满整个
  窗口。
- 工具栏分两组：**左上角管对方画面**（旋转 90°、水平镜像、置顶、锁），
  **右上角管本地回显小窗**（旋转、镜像、回显开关）。
- 窗口**默认是锁定的**（不能被拖动/改大小，防止误拖）；点锁图标解锁后即可拖动。
  **双击画面 = 全屏**。
- 窗口大小按对方画面等比缩放到 640 像素上限；分辨率变化时自动调整。
- 视频窗口与通话面板的位置在拖动后会被记住（视频窗口的置顶、本地回显的旋转/镜像也会记住）。
- 网页订阅了视频时，软电话自己的视频窗口会隐藏（画面在网页显示）——这是设计行为。

### 通话记录

- 主窗口顶栏「通话记录」进入。每条记录两行：方向图标（呼出 ↗ / 呼入 ↙，绿色=已接通、
  红色=未接通）、号码或名称（命中通信录时带名称与 ★）、时间、状态与时长
  （如「已接通 · 通话 1 分 20 秒」「未接听 · 振铃 5 秒」）；视频通话带摄像头小标。
- 顶部可按号码/名称**筛选**（输入停顿后自动过滤）；每行右侧的图标可直接**呼叫 / 视频呼叫**
  （回拨）。
- **选择**：单击选中（再点取消）、Shift+单击加选、**按住拖动框选连续多条**。
- **右键菜单**：删除这条 / 删除选中的 N 条；号码在通信录里还有「编辑联系人」「删除联系人」，
  不在则有「添加到通信录」。顶部「清空通话记录」清空全部（二次确认）。
- 列表滚动到底部自动加载更早的记录（**永久保留，不自动清理**）。
- 状态文案：已接通 / 未接听 / 拒接 / 取消 / 未接通 / 已中断（异常退出遗留的"进行中"
  记录会在下次启动标记为「已中断」）。

### 通信录

- 主窗口顶栏「通信录」进入。顶部有两个标签页：**常用联系人 / 所有联系人**（默认打开常用）；
  右上角四个图标按钮：**新增（＋）/ 导入 / 导出 / 清空**。
- 每行显示**号码 + ★（常用标记）**、**名称 + 备注**（备注以灰色小字直接显示），
  行尾图标可直接**呼叫 / 视频呼叫**。
- **搜索**（所有联系人页）：支持**汉字、拼音全拼、拼音首字母**以及号码、备注。
- **新增 / 修改**：对话框里填号码、名称（必填）、备注，勾选「常用联系人」。
- **右键菜单**：设为常用 / 取消常用、修改、删除；多选时可批量设常用与批量删除。
- 号码匹配是**规范化比较**（`sip:` 前缀、尖括号、空格/横线等都会被忽略），所以
  `2999` 与 `sip:2999@服务器` 视为同一号码。
- **导入/导出 CSV**：表头为「号码,名称,备注,常用」（UTF-8 带 BOM，Excel 可直接打开）。
  导入按号码合并：**已存在的只覆盖号码/名称/备注，★ 常用只增不减**。
- 来电、通话记录命中通信录时自动显示名称与 ★；把鼠标停在**通话面板的对端名称**或
  **通话记录行**上约 0.3 秒，会弹出备注气泡。

### 托盘

- 托盘图标：**绿色话机 = 已注册**；**红色 = 未注册/注册失败**。
- **单击托盘图标**即可唤出主界面；右键菜单：「显示主界面」/「退出」。

### 托盘图标没反应 / 没有窗口？（仅托盘无 UI 版）

如果你装的是 **mti-sip-phone-no-ui**（「仅托盘无 UI 版」），那**没有桌面界面是正常的**：

- 程序只有托盘图标，**不会弹出任何窗口**（没有主界面、通话面板、视频窗口、更新提示窗）；
- **左键点托盘图标** → 用系统默认浏览器打开**网页控制台**（`http://127.0.0.1:<端口>/`），
  拨号、接听、通话记录、通信录、配置都在那里做（见下面「网页控制台」一节）；
- **右键点托盘图标** → 菜单两项：「打开控制台」「退出」；
- 图标颜色含义与完整版一致（绿 = 已注册、红 = 未注册）。

它与完整版是**替代关系**：两者共用同一份配置与系统注册，**同一台机器上只能运行一个**
（先启动的那个占用，后启动的会退出）。

### 网页控制台

浏览器打开 `http://127.0.0.1:8765/`（端口以「配置 → 应用」里的实际端口为准，见下），
就是完整的控制台（顶栏左侧是应用名「MTI 软电话」，右侧是连接/注册/坐席状态），
顶部导航分五页（当前页用下划线高亮；网址里的 `#/call` 这类是页面定位，可直接收藏）：

| 页面 | 能做什么 |
| --- | --- |
| 通话 | 点「呼叫」弹出**拨号对话框**（两个页签：**拨号盘**——输入号码或名称，带通信录与最近呼叫建议、号码盘；**在线座席**——仅坐席模式显示），发起呼叫/视频呼叫、咨询/转移/会议都从这里进；接通后拨号盘图标可发 DTMF。另有来电接听/挂断/保持、麦克风与扬声器开关和音量、多方话务面板（咨询/三方/监听/会议，与桌面版一致）、视频订阅（远端 + 本地画面，可旋转/镜像）、自动接听开关、软件更新（下载 / 安装并重启） |
| 通话记录 | 按号码筛选、滚动加载、多选删除、清空、直接回拨（含视频回拨） |
| 通信录 | 搜索、常用筛选、新增/编辑/删除、批量设常用、清空、CSV 与 JSON 导入导出 |
| 配置 | SIP 账户、音频设备与音频预处理、视频与摄像头、日志、开机自启与 WS 端口（含「立即重启」）、自动更新（站点/周期/立即检查） |
| 诊断 | 运行信息（版本/平台/本机号码/端口）、事件日志（默认不回显视频帧，可清空）、**sip:// 拉起链接生成器**（填服务器/账号/传输/实例槽位，生成可点击的链接，也可复制给别的机器） |

顶部有一条**常驻通话条**：来电/通话时在任何页面都能接听、挂断、保持（无 UI 版没有
桌面通话面板兜底，这条是唯一入口）。

> 注意：网页是**内嵌在程序里**的，改端口/换版本后请重新打开页面；页面地址随端口变化
> （配置页里改完端口会提示新地址，重启后生效）。

#### 让别的电脑也能打开控制台（可选，谨慎使用）

配置页「应用」里有 **「允许远程连接」** 勾选项（**默认不勾**）：勾上后软电话不再只监听本机，
而是监听 `0.0.0.0`，**同一网段的其他电脑/手机**也能用浏览器打开 `http://<这台机器的IP>:端口/`
来操作它（比如机器只当话机用、人在另一台电脑上拨号）。改完要**重启**才生效。

> ⚠️ **这个网页接口没有任何密码/鉴权**：勾上之后，能连到这台机器的任何人都可以拨打电话、
> 查看通话记录与通信录、修改配置，甚至重启程序。**只在可信任的网络里临时开启**，
> 不用的时候记得取消勾选并重启；公网可达的机器上不要开。

## 5. 高级用法

### 用 sip:// 链接拉起软电话（网页集成）

网页/其他程序可用自定义协议链接拉起软电话并自动配置账号：

```
sip://账号:密码@服务器:端口          # 明文信令（UDP）
sip://账号:密码@服务器:端口?transport=tcp
sips://账号:密码@服务器:端口         # TLS 信令（默认端口 5061）
sip://账号:密码@服务器:端口?instance=2   # 用沙箱实例 2 启动（见下）
sip://账号:密码@服务器:端口?updatesite=https://update.wuzm219.cn  # 同时写入更新站点（省略 = 不改）
```

> 注意：链接里含明文密码，只适合内部系统使用。

### 多开（沙箱实例）

默认**单实例**（重复启动只会唤出已有窗口）。联调或"两个账号互相打"时，
用 `-instance N`（N=1–99）或上面的 `?instance=N` 启动**独立实例**：
每个实例有自己的配置、通话记录、通信录、日志与端口，互不干扰。
不带参数启动的仍是主实例，日常使用不需要关心这个。

### 网页控制软电话（自建页面）

网页可以通过本地 WebSocket 控制软电话（拨号、接听、挂断、视频订阅、通话记录、
通信录增删改查、配置读写、触发更新）。SDK 由软电话自带：
`http://127.0.0.1:8765/sdk/sip-phone-sdk.js`；自带的控制台就是它的完整示例
（`http://127.0.0.1:8765/`）。集成方法见 [sdk-guide.md](sdk-guide.md)，
协议细节见 [ws-protocol.md](ws-protocol.md)。

> 安全提示：本地 WS/HTTP **只监听 127.0.0.1、无鉴权**——本机的任何程序或网页都能控制
> 软电话。请勿在公用电脑上无人值守运行。

## 6. 自动更新

1. 配置了「更新站点」后，程序**启动时**和之后**按周期**（默认 5 分钟）查询是否有新版本；
   配置页里的「立即检查」也可手动查询。
2. 有新版时，右下角弹出**更新提示窗**（主窗口顶部同时出现一条「更新 vX.Y.Z」提示行），
   显示当前版本、平台与下载来源主机名。
3. **你点「立即更新」后**才下载（旁边的「稍后」= 先不更新）；下载中可以「取消下载」；
   下载完成按提示**重启安装**。**不点就永远不下载**——不会背着你升级。
4. 通话中不弹更新提示（结束通话后补弹）；下载完成后如果还在通话，会等通话结束再重启。
5. 更新包会做完整性校验（sha256），失败会提示原因，可「重试」。
6. **网页控制台也能触发更新**（无 UI 版没有桌面提示窗，只能从网页操作）：网页的「通话」页
   会显示更新提示条，点「下载」「安装并重启」即可；配置页还有「立即检查」。
   同样**必须你自己点**，程序不会背着你升级。
7. 不知道更新站点地址时，配置页（桌面与网页都有）的「**使用主站点**」按钮可一键填入官方
   站点；sip:// 拉起链接也可带 `updatesite` 参数直接指定站点（见「5. 高级用法」）。

## 7. 故障排查

### 状态圆点红色 / 一直显示"注册失败"

1. 检查**服务器地址、端口、账号、密码**是否与管理员给的一致（密码区分大小写）。
2. 检查**传输方式**：服务器要求 TLS 时选 `tls`；端口通常是 5061 而不是 5060。
3. 看状态圆点旁提示的失败原因（如「超时/无响应」= 网络不通或防火墙拦截；
   「403」= 账号密码错或被服务端拒绝；证书错误 = 服务器证书不被信任，
   内网自签证书可取消勾选「校验服务器证书」）。
4. 确认本机能访问服务器（`ping` / 同网段的其他软电话是否正常）。
5. 局域网内**建议关闭 STUN**，否则可能把注册地址改成探测到的公网地址导致异常。

### 能打出去，但别人打不进来

- 常见于 NAT 后的环境。确认服务器端配置正确，并保持「rport」开启。
- TLS/TCP 传输下保持程序常驻（连接需要保活）；不要把程序退出到"完全关闭"。
- 若刚刚修改过配置，等注册状态变绿（重新注册成功）再试。

### 通话没有声音

1. **先看通话面板的两个开关**：麦克风/扬声器是否被点成了关闭（浅灰底红图标）；
   检查**音量是不是被滚轮调到了 0%**（按钮底色空了就是 0）。
2. 检查配置页的**音频设备选择**：耳机插拔后设备 ID 可能变化，点「刷新设备」重选。
3. 外放时对方听到回声 → 保持「回声消除」开启；仍明显时改用耳机。
4. 单向无声（对方听不到你）：检查系统里麦克风的**隐私权限**（Windows：设置 → 隐私 →
   麦克风，允许桌面应用访问）。
5. 都不行时：勾选「记录 SIP 信令」，复现一次通话，把日志交给技术支持。

### 视频看不到 / 黑屏

- 对方看不到你的画面：配置页确认摄像头没被选成「禁用」、没被其他程序（OBS、会议软件）
  独占；摄像头指示灯亮不亮。
- 你看不到对方：先确认**本次通话是视频通话**（普通接听 = 不收视频，这是设计）；
  再确认「启用视频通话」总开关是勾选状态。
- 画面卡顿/模糊：调低分辨率、帧率或码率（视频设备区域）。
- 视频窗口"没有出现"：纯音频通话本就不显示视频窗口。

### 程序"突然消失"了

- 托盘图标不见了 ≠ 程序崩溃：可能只是**主窗口被关闭**（隐藏到托盘）。看托盘区。
- 真崩溃时程序会留下现场日志：打开日志目录，看 `crash*.log`（有内容 = 崩溃过一次，
  交给技术支持）；**空文件 = 不是崩溃**（正常退出或被杀掉）。
- 崩溃可能与视频/摄像头驱动有关，反馈时请附上当时的操作。

### 更新失败

- 提示里会写失败原因（网络不通 / 校验失败 / 文件被占用）。
- 手动下载更新站点上的新版本覆盖旧文件亦可（退出程序后再覆盖）。
- **Windows 上程序运行中不能覆盖自身 exe**，请先托盘退出。

### 收不到桌面通知（未接来电）

- Windows：首次通知需要系统登记应用标识，个别精简系统会拦截；不影响通话记录里的未接记录。
- Linux：需要桌面环境的通知服务（D-Bus）。

### 其他

- **Windows 7 上打不开**：不支持，程序要求 Windows 10 及以上（见第 2 节）。
- **托盘图标红色但能打电话**：图标颜色跟随注册状态，说明当前未注册成功（见第一条）。

### 反馈问题时请附上

1. 日志目录里的**当天日志**（`logs/` 下按日期命名的文件），以及 `crash*.log`（如果有）。
2. 复现步骤与时间点；通话问题建议先勾选「记录 SIP 信令」复现一次
   （日志中的密码与加密密钥已自动打码，可以安全外发）。

## 8. 附：数据与文件位置

| 内容 | 位置（Windows / Linux） |
| --- | --- |
| 配置 | `%APPDATA%\mti-sip-phone\config.json` / `~/.config/mti-sip-phone/config.json`（**密码已加密存储**） |
| 通话记录 | 同目录 `call-log.db`（SQLite） |
| 通信录 | 同目录 `contacts.db`（SQLite） |
| 日志 | 同目录 `logs/`（按大小滚动、自动压缩归档） |

| 沙箱实例 | 同目录 `instances/<N>/`（多开时各自一份） |
| 程序本体（自安装后） | `%APPDATA%\mti-sip-phone\` / `~/.local/share/mti-sip-phone/`（首次运行时自动复制过去，自动更新替换的也是这份） |

版本信息可在配置页与网页控制台的「诊断」页看到（含编译平台/架构与构建时间）。
