# mti-sip-phone 需求文档

> 本文档记录项目的全部需求，按模块与编号组织。需求变更时直接修改对应条目，并在 [changelog.md](changelog.md) 中登记变更。
>
> 当前版本：**1.0.3**（dev 开发中；1.0.2 已发布到 master）

## 1. 项目概述

| 项 | 说明 |
| --- | --- |
| 项目定位 | 跨平台 SIP 软电话客户端（桌面 GUI 应用） |
| 技术栈 | Go 语言 |
| 目标平台 | Windows、Linux，架构 x86_64 与 arm64 |
| 对接服务端 | 标准 SIP 服务器，遵循 RFC 3261，不绑定具体厂商实现 |
| 媒体能力 | 完整语音通话（PCMA / PCMU，真实收发 RTP，接入本地音频设备） |
| 使用场景 | 网页操控型软电话：常驻托盘，通过本地 WebSocket 由网页控制，亦可独立拨号 |

## 2. 文档约定

| 项 | 说明 |
| --- | --- |
| 编号规则 | `REQ-<模块代号>-<三位序号>`，如 `REQ-WS-001` |
| 优先级 | **P0** 必须实现（1.0.0 交付范围）/ **P1** 重要 / **P2** 可选 |
| 状态 | 待确认 / 已确认 / 开发中 / 已完成 / 已废弃 |

## 3. 模块划分

| 代号 | 模块 | 说明 |
| --- | --- | --- |
| ACC | 账户与注册 | 账户配置、SIP 注册 |
| CALL | 呼叫控制 | 呼出、呼入、振铃、接听、挂断、通话记录 |
| MEDIA | 媒体与音频 | PCMA/PCMU、麦克风与扬声器选择 |
| UI | 界面交互 | 托盘、主界面、来电窗口、通话面板、设置 |
| WS | 本地 WebSocket 接口 | 网页通过本机 WS 控制与监听软电话 |
| PROTO | sip:// 协议 | 网页通过 sip:// 拉起软电话并携带注册信息 |
| SDK | JS SDK | 供网页集成，封装 WS 控制与事件监听 |
| UPD | 自动更新 | 版本/架构上报、前端告知新版本、下载替换与重启 |
| TEST | 测试页面 | 用 JS SDK 实现的拨号/接听/挂断演示页 |
| LOG | 日志 | 本地日志文件、SIP 信令与关键信息记录 |
| NFR | 非功能需求 | 跨平台构建、稳定性、安全 |

### 4.10 自动更新（UPD）

## 6. 1.0.0 交付范围

> 已确认口径：**实现 P0 需求**。

**纳入 1.0.0**：

- 账户注册（UDP / TCP + Digest），注册状态与自动续注册
- 呼叫：呼出、呼入、振铃、接听、拒接、挂断、静音、失败提示
- 媒体：PCMA / PCMU 全双工，麦克风与扬声器选择，SDP 协商，抖动缓冲
- 界面：托盘常驻、双击唤出主界面（拨号 + 配置）、来电置顶振铃窗口、通话置顶面板、中文界面
- WS 接口：拨号 / 接听 / 挂断 / 拒接控制，振铃 / 建立 / 挂断 / 注册状态事件，CORS
- sip:// 协议：注册协议、解析注册信息、写入配置并启动注册
- JS SDK + 测试页面：随发布物分发，网页拨号 / 接听 / 挂断演示
- 日志：分级写文件、SIP 信令记录、滚动、脱敏
- 构建：Windows / Linux × x86_64 / arm64

**排除项（后续版本）**：TLS(SIPS)、通话记录、DTMF、音量控制、AEC/NS/AGC、G.722/Opus、SRTP、录音、桌面通知、WS 状态查询接口、多客户端广播、单实例、TS 类型声明等 P1/P2 条目。

**架构约束**：虽然本期不实现，但 1.0.0 的代码结构不得妨碍后续引入：

- 编解码、音频前后处理需设计为可插拔
- 通话事件出口（WS 事件推送）需独立成层，便于后续扩展其他出口（如 CTI 平台对接）
- 配置模块需支持 sip:// 拉起的运行时写入
