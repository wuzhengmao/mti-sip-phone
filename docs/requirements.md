# mti-sip-phone 需求文档

> 本文档记录项目的全部需求，按模块与编号组织。需求变更时直接修改对应条目，并在 [changelog.md](changelog.md) 中登记变更。
>
> 当前版本：**1.0.13**（已定版并合并到 master；更新时间 2026-10-06）

## 1. 项目概述

| 项 | 说明 |
| --- | --- |
| 项目定位 | 跨平台 SIP 软电话客户端（桌面 GUI 应用） |
| 技术栈 | Go 语言 |
| 目标平台 | Windows（x86_64、x86 32 位、ARM64）与 Linux（x86_64、arm64） |
| 对接服务端 | 标准 SIP 服务器，遵循 RFC 3261，不绑定具体厂商实现 |
| 媒体能力 | 完整语音通话（PCMA / PCMU / Opus，真实收发 RTP，接入本地音频设备） |
| 使用场景 | 网页操控型软电话：常驻托盘，通过本地 WebSocket 由网页控制，亦可独立拨号 |

## 2. 文档约定

| 项 | 说明 |
| --- | --- |
| 编号规则 | `REQ-<模块代号>-<三位序号>`，如 `REQ-WS-001` |
| 优先级 | **P0** 必须实现（1.0.0 交付范围）/ **P1** 重要 / **P2** 可选 |
| 状态 | 待开发 / 待验证 / 开发中 / 已完成 / 已废弃 |

## 3. 模块划分

| 代号 | 模块 | 说明 |
| --- | --- | --- |
| ACC | 账户与注册 | 账户配置、SIP 注册 |
| CALL | 呼叫控制 | 呼出、呼入、振铃、接听、挂断、通话记录 |
| CONTACT | 通信录 | 联系人（号码/名称/备注/常用）、拼音搜索、CSV 导入导出 |
| MEDIA | 媒体与音频 | PCMA/PCMU/Opus、麦克风与扬声器选择 |
| UI | 界面交互 | 完整版：托盘、主界面、来电窗口、通话面板、设置；仅托盘无 UI 版：只有托盘 |
| WS | 本地 WebSocket 接口 | 网页通过本机 WS 控制与监听软电话 |
| PROTO | sip:// 协议 | 网页通过 sip:// 拉起软电话并携带注册信息 |
| SDK | JS SDK | 供网页集成，封装 WS 控制与事件监听 |
| UPD | 自动更新 | 版本/架构上报、SDK 定时查询更新站点、下载替换与重启 |
| WEB | 网页控制台 | 用 JS SDK 实现的完整控制端：通话 / 通话记录 / 通信录 / 配置 / 诊断五个页面（1.0.15 取代原「测试页面」，并兼作仅托盘无 UI 版的唯一界面） |
| LOG | 日志 | 本地日志文件、SIP 信令与关键信息记录 |
| REL | 发布与版本 | 版本号约定（开发版 -rc / 正式版）、更新站点发布脚本与发布物元数据 |
| NFR | 非功能需求 | 跨平台构建、稳定性、安全 |

| REQ-ACC-011 | SIP 服务器相关配置修改保存后，立即取消旧注册并以新配置重新注册。**1.0.18 修订**：**换账号**（服务器/端口/传输/账号/认证 ID 任一变化）时**先给旧账号发 expires=0 的 REGISTER 让它立即过期**，再注册新账号——此前只停本端旧注册循环，服务端旧绑定要等自然过期（默认 300 秒），期间打旧号码仍会送到本机。顺序与口径：先停旧注册循环（防它续注册）→ **在切配置之前**发注销（Contact 必须与注册时一致，服务端按 Contact URI 匹配删除）→ 静默路径（不发注册状态，界面不闪"未注册"）→ 尽力而为（最多等 2 秒，失败只记日志，不阻断新注册）。纯改密码/显示名/STUN 等的重注册**不打扰服务端** | P0 | 已完成 |

| REQ-ACC-022 | **SIP 域名（可选）**：配置页 SIP 账户新增「域名」输入框（`account.domain`），**留空 = 用 SIP 服务器地址做域名**（历史行为一字不变）。配了域名后，**URI 里的域**用域名——REGISTER 的 R-URI/From/To、呼出 INVITE 的 From 与 To/R-URI（纯号码补全为 `sip:号码@域名`）；**网络目的地仍是 Server:Port**（域名多半只在服务器内部解析，本机不一定解析得了）：REGISTER 用 `SetDestination`，INVITE 用首条 `Route: <sip:服务器:端口;lr>`（与出站代理同一手法，**代理配置优先**）。Contact 不受影响（永远是本机地址）。域名允许带 `sip:`/`sips:` 前缀、`user@` 与端口，规范化时一律去掉（见 `config.NormalizeDomain`） | P1 | 已完成 |

| REQ-ACC-021 | **心跳间隔自学习 + 超时恢复**：从**传输层**收到的 OPTIONS 学习探测间隔（至少 5 条心跳取平均武装判定；亚秒级重发不算样本；间隔突增 >3× 视为探测重启、样本清零重学），学成与间隔秒级变化记 info；**超过 2.5 个心跳周期**没收到探测即判为**服务端掉线**：先把注册状态置**未注册**（界面圆点与托盘图标变红、失败原因显示"服务端心跳超时"），再立即发起一次 REGISTER（不等 0.7×expires 的续注册），触发后复位、等下一条心跳重新武装——服务器不发 OPTIONS（不支持 optchk）时恒不触发 | P1 | 已完成 |
| REQ-UI-015 | 界面注册状态与托盘图标颜色必须与实际注册状态一致（启动时从核心状态快照初始化，而非仅依赖事件） | P0 | 已完成 |
| REQ-UI-016 | 设置项修改后自动保存（本地 SIP 监听端口、音频设备选择），无需手动点保存 | P0 | 已完成 |
